Adaptive narrative in video games

Bachelor's thesis exploring a reusable closed-loop narrative adaptation system and its integration with multiple game engines.

About this project

Research and development project. This public profile covers its purpose and high-level approach; the source repository is private.

Goals

Design and implement a reusable system for exploring closed-loop narrative adaptation and study how it can be integrated with existing game engines.

Approach

Keep the adaptation system separate from connected games to study different ways of observing, deciding and responding. This page describes the general approach without disclosing private working materials.

Game engine integration

Examine which information different engines can expose and how narrative interventions might be applied. Specific capabilities must be assessed for each integration.

Status and documentation

Ongoing research and development project. Public results will be added after editorial review; the working repository is not public.
